# Zeiterfassung Bludau – Anleitung für Admins (Büro/Geschäftsführung)

Anmeldung: Startseite → „Verwaltung (Admin)“ → Benutzername + Passwort (+ Code aus der Authenticator-App, falls 2FA aktiv).
Die Admin-Sitzung endet nach 30 Minuten ohne Aktivität.

## Täglich

| Menü | Aufgabe |
|---|---|
| **Übersicht** | Heute abwesend, offene Anträge, **Hinweise Arbeitszeitgesetz** (über 10 Std., Ruhezeit < 11 Std., Pause fehlt, nicht ausgestempelt) → „Tag ansehen“ → ggf. korrigieren → „Erledigt“ |
| **Anwesenheit** | Live-Tafel: da / Pause / abwesend / **fehlt** / gegangen – aktualisiert sich selbst |
| **Anträge** | Urlaubs-, Storno- und Korrekturanträge genehmigen oder ablehnen (Ablehnung mit Begründung). Hinweis bei Unterschreitung der Mindestbesetzung |
| **Krankheit** | Krankmeldungen erfassen/verlängern, „eAU abgerufen“ abhaken, **Krank im Urlaub** → nach Prüfung „Urlaubstage zurückbuchen“, Hinweise **6 Wochen** und **BEM** |

## Zeiten korrigieren

**Zeiten** → Mitarbeiter wählen → Tag „Bearbeiten“ → Zeilen (Arbeit/Pause) anpassen → **Begründung (Pflicht)** → Speichern.
Originalstempelungen bleiben sichtbar, jede Änderung steht im Änderungsprotokoll und der Mitarbeiter wird benachrichtigt.
Unten auf der Seite: **Zeitkonto buchen** (Startsaldo/Übertrag bei Einführung, Korrektur, Auszahlung, Freizeitausgleich in Stunden).

## Mitarbeiter

**Mitarbeiter → + Mitarbeiter anlegen**: Personalnummer, Name, Abteilung, Eintritt, Wochenstunden, Rollen.
Die **Start-PIN** wird nur einmal angezeigt – notieren und persönlich übergeben.
In **Details**: Stammdaten/Rollen, Abteilungsleiter, **Arbeitszeitmodell** (gültig ab), **Urlaubsanspruch** und **Übertrag/Übernahme** je Jahr, **Zeitkonto-Beginn**, PIN zurücksetzen, Admin-Passwort/2FA zurücksetzen, **sperren**, **Austritt**, **Datenauskunft (DSGVO)**.

## Monatsende

1. **Anträge** leeren (offene Anträge erledigen).
2. **Monatsabschluss & Export** → Vormonat → Werte prüfen → **„Alle … abschließen“**.
3. **Excel herunterladen** → an Lohnbüro/Steuerberater.
4. PDF-Monatsnachweise ablegen (optional); Mitarbeiter bestätigen ihren Nachweis in der App.
Fehler entdeckt? → „wieder öffnen“ (mit Begründung), korrigieren, erneut abschließen.

## Einrichtung / Einstellungen

- **Feiertage**: Niedersachsen automatisch; Heiligabend/Silvester als halbe Tage per Klick; Betriebsferien eintragen (als Urlaub verrechnet).
- **Terminals**: Code erzeugen → am Tablet `/terminal` öffnen → Code eingeben.
- **Einstellungen**: Stempeln vom Handy (optional nur Firmen-WLAN), Arbeitszeit zählt ab (06:00), Pausenregel (betrieblich 45 Min. ab 6 Std.), Rundung, Urlaub (30 Tage, Verfall 31.03.), Mindestbesetzung, Abwesenheitsarten, Aufbewahrung, **2FA-Pflicht für Admins**.
- **Mein Zugang**: eigenes Passwort, **2FA einrichten** (dringend empfohlen).

## Datenschutz im Alltag

- Krankmeldungen: **nur Zeitraum und AU-Status** – keine Diagnosen eintragen oder abfragen.
- Admin-Zugänge nicht teilen; jeder Admin hat ein eigenes Konto.
- Bei Verlust eines Firmenhandys: Mitarbeiter **sperren** bzw. PIN zurücksetzen.

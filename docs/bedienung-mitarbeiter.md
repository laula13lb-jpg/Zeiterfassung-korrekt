# Zeiterfassung Bludau – Kurzanleitung für Mitarbeiter

## Stempeln am Werkstatt-Tablet

1. **Namen antippen**
2. **PIN eingeben** → „Weiter“
3. Passenden Knopf drücken:
   - **Kommen** (grün) – Arbeitsbeginn
   - **Pause** (gelb) – Pause beginnt · **Pause Ende** (blau) – weiter geht's
   - **Gehen** (rot) – Feierabend
4. Bestätigung lesen („Guten Morgen, Max – eingestempelt 07:02“). Das Tablet geht von selbst zum Start zurück.

**Kein Netz?** Einfach normal stempeln – die Zeit wird gespeichert und automatisch nachgereicht.

## Pausen

Bitte Pausen stempeln (bei uns z. B. 20 + 25 Minuten). Wird keine Pause gestempelt, zieht das System ab 6 Stunden Arbeit automatisch 45 Minuten ab.
Arbeitszeit **vor 6:00 Uhr** wird nicht angerechnet.

## Auf dem Handy

Adresse im Browser öffnen: **[https://zeit.autoklinik-bludau.de]** → „Anmelden (Mitarbeiter)“ → Namen antippen → PIN.

| Menü | Was du dort machst |
|---|---|
| **Heute** | Status, heutige Arbeitszeit, Zeitkonto, Neuigkeiten |
| **Meine Zeiten** | Monatsübersicht Soll/Ist, Saldo, **Korrektur beantragen** („vergessen auszustempeln“), Monatsnachweis als PDF, Monatsnachweis bestätigen |
| **Urlaub** | Resturlaub, **Urlaub beantragen**, Anträge zurückziehen/stornieren, Abwesenheiten der Abteilung |
| **Krankmeldung** | Krank melden (nur Zeitraum – **keine Diagnose!**), verlängern |
| **PIN ändern** | eigene PIN ändern |

**Erstes Anmelden:** Du bekommst vom Büro eine Start-PIN und vergibst dann deine eigene (4–6 Ziffern, nicht 1234, keine Jahreszahl/Geburtstag). **PIN niemandem verraten.**
5 falsche Versuche → 5 Minuten gesperrt. PIN vergessen → Büro setzt sie zurück.

## Krank?

Bitte am ersten Tag **telefonisch im Büro melden** und zusätzlich in der App unter „Krankmeldung“ eintragen. Zum Arzt gehen; die Krankmeldung (eAU) ruft das Büro bei der Krankenkasse ab.
Wirst du **im Urlaub krank**, melde das ebenfalls – mit ärztlicher Bescheinigung werden dir die Urlaubstage zurückgebucht.

## App auf den Startbildschirm legen

- **Android (Chrome):** Seite öffnen → Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.
- **iPhone (Safari):** Seite öffnen → Teilen-Symbol □↑ → „Zum Home-Bildschirm“.

Fragen? → Büro.
